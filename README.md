# Smart Indoor Lighting Control System

**University of Tehran — Research and Engineering Project**

An integrated platform combining daylight-aware lighting control, physics-based simulation, embedded electronics, sensing, and constrained optimization.

> Project documentation in progress. Only verified and authorized materials should be uploaded.

## Overview
The project studies indoor illuminance modeling, sensor placement, daylight estimation, and energy-efficient lighting control with laboratory validation.
